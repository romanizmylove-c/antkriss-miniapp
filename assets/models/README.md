# ANTKRIS 3D model

Put `ANTKRIS_black_L_photo_projected.glb` in this folder. The app looks for exactly `assets/models/ANTKRIS_black_L_photo_projected.glb`.

Until the model is hosted, users can choose the GLB from their device in the 3D tab and it will be stored locally in their browser (IndexedDB).

The imported model is a visual-hull prototype, not a production-ready UV-mapped asset.

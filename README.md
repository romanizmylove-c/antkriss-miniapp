# ANTKRIS Mini App — интерактивный прототип

Адаптивный прототип магазина одежды ANTKRIS в светлом стиле. Главная, каталог, карточка товара, категории, поиск, избранное и демо-корзина. Реальные фотографии из предоставленных материалов бренда.

## Просмотр
После включения GitHub Pages: `https://romanizmylove-c.github.io/antkriss-miniapp/`.

Чтобы опубликовать: Settings → Pages → Build and deployment → Deploy from a branch → `main`, папка `/(root)` → Save.

## Telegram
В BotFather для кнопки **Menu Button** или Web App укажите HTTPS-ссылку сайта после публикации GitHub Pages. Для рабочего магазина дополнительно нужны проверка данных Telegram Web App, серверная часть, данные товаров и оформление заказов.

## Статус
**Демонстрационный прототип**, не подключён к реальной базе товаров, остаткам или оплате. Цена в карточке худи показана по материалу от 2025 года и может быть неактуальной.

Технологии: HTML, CSS, JavaScript (без сборки).
